## How to run and roll back

From the monorepo root, `cd discovery-demo/web && pnpm typecheck && pnpm test && pnpm build`; then `cd .. && node start.mjs --port 8787` (requires `uv`, serves the Python development runtime at 127.0.0.1). Native build commands are in `discovery-demo/README.md`. Settings → uncheck Improved ranking (v2) for the v1 scorer; history stays stored. Switching branches does not clear the data; avoid resets. For platform limitations and exact measured comparison see `provider-capabilities.md` and `evaluation.md`.
