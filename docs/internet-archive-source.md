# Internet Archive full-song source (0.10.8 / 0.7.8)

The source chain now tries licensed Internet Archive single-track uploads after YouTube Music, YouTube videos, SoundCloud, Bandcamp and Audius. It uses the Archive's public search and metadata endpoints; no account, key or additional downloader is installed. It offers a direct original MP3/M4A/FLAC only when item metadata declares a recognized Creative Commons or CC0 license, one original audio file has a credible full duration and size, and title/artist/duration pass the same strict recording matcher as other sources. The native yt-dlp must finish the file before the song becomes locally ready. Browser and native host/path gates permit only direct Archive audio-file download URLs; they reject arbitrary Archive pages and redirects in query parameters. This trusts the uploader's license declaration; it is not independent proof that an uploader owns the rights.

Live smoke: `/metadata/cold-funk-by-kevin-macleod` identifies a 288.29-second original MP3 under CC BY-ND 4.0. On both packaged Android 0.10.8 and Windows 0.7.8, yt-dlp downloaded it into private cache, the native bridge reported a locally ready file, and a media element decoded the entire 288.287-second file and advanced playback. The downloaded music is **not** bundled in either package or source archive and was **not** copied into the owner's kept Music folder. Invalid archive URLs were rejected on Android; page and Windows guards have matching unit tests.

This is extra coverage, **not** a claim of 97/97. The original 219-second *Plant Island* recording matched an unofficial SoundCloud upload by fingerprint, but that upload was marked all-rights-reserved and did not indicate permission to download. No full downloadable 290-second Piano Cartel *Aria Math* recording was verified. Internet Archive searches did not match either exact recording. Neither a different version, a 30-second preview, an unlicensed upload nor a filtered smaller denominator counts as the missing song. The owner-kept Music folder remains outside discovery expiry and reset.
